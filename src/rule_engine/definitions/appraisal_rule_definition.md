# 鉴定费（appraisal）规则定义

- 所属分类：**A 类 Rule-based**
- 规则实现：`src/rule_engine/rule_generic.py::AppraisalRule`（模板 `CapRule`）
- JDI：78.49（**排名 1**，司法确定性最高）；有效样本 843；P(SR=1)=0.909，mean_SR=0.936，std_SR=0.234

## 1. 司法依据

- 《诉讼费用交纳办法》及司法实践：鉴定费属于**诉讼过程中实际发生的费用**，由人民法院根据**鉴定机构的收费票据**据实确定，通常作为诉讼费用由败诉方负担或按责任比例分担。

法律特征：属于**凭据据实、确定性最高**的项目——金额由第三方鉴定机构出具票据确定，法院几乎不作实质裁减，故 P(SR=1) 高达 0.909，JDI 排名首位。

## 2. 输入字段（全部为判前信息）

| 字段 | 说明 |
|---|---|
| `appraisal_claim` | 鉴定费请求金额（判前可得） |
| 训练折统计量 `R` | 训练折内 SR=1 样本的 `appraisal_claim` 的 95 分位（**仅训练折计算**） |
| 训练折 `median(SR)` | 退化兜底值 |

**禁止使用**：任何 `*_award` 判后字段作为预测输入。

## 3. 计算逻辑

```
R   = quantile( appraisal_claim | SR == 1 , q = 0.95 )   # 训练折内估计（支持率极高，取高分位）
SR̂ = min( 1 , R / appraisal_claim )                      # claim > 0
SR̂ = 0                                                   # claim = 0（未主张）
```

由于该分项全额支持率极高，R 取 95 分位以覆盖绝大多数正常鉴定费用；仅对极个别异常高额请求做压缩。

## 4. 限制条件

1. **费用分担方式**：鉴定费可能被法院按责任比例分担而非全额支持，规则无法识别个案的分担口径。
2. **缺少鉴定项目数**：多次鉴定（伤残等级、护理依赖、后续医疗费）的费用合并为一个字段，无法拆分。
3. **票据可得性**：若原告未实际缴纳或票据缺失，规则仍会给出全额支持，造成高估。
4. **R 的高分位敏感性**：q=0.95 使 R 对训练折内极端值较敏感，需在 Stage 6 检验 q 的敏感性。
