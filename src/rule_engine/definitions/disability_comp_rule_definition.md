# 残疾赔偿金（disability_comp）规则定义

- 所属分类：**A 类 Rule-based**
- 规则实现：`src/rule_engine/rule_disability.py::DisabilityCompRule`（模板 `StratifiedMedianRule`）
- JDI：67.30（排名 3）；有效样本 614；P(SR=1)=0.559，mean_SR=0.921，median_SR=1.000

## 1. 司法依据

- 《民法典》第一千一百七十九条：造成残疾的，还应当赔偿辅助器具费和残疾赔偿金。
- 《最高人民法院关于审理人身损害赔偿案件适用法律若干问题的解释》第十二条：残疾赔偿金根据**受害人丧失劳动能力程度或者伤残等级**，按照受诉法院所在地上一年度城镇居民人均可支配收入标准，自定残之日起按二十年计算（六十周岁以上年龄每增加一岁减少一年，七十五周岁以上按五年计算）。

法律特征：属于**法定公式型**项目，其中**伤残等级**是法定公式的直接输入（伤残赔偿系数：1 级最重 100%，10 级最轻 10%），因此以伤残等级分层是规则的自然实现。

## 2. 输入字段（全部为判前信息）

| 字段 | 说明 |
|---|---|
| `disability_level_clean` | 伤残等级（0 = 无伤残等级；1–10 = 伤残等级，1 级最重、10 级最轻；25 → NaN） |
| `disability_comp_claim` | 残疾赔偿金请求金额（判前可得） |
| 训练折分层表 | 各伤残等级对应的训练折 SR 中位数（**仅训练折计算**） |

**禁止使用**：任何 `*_award` 判后字段作为预测输入。

## 3. 计算逻辑

```
对每个伤残等级 l：  M_l = median( SR | disability_level_clean == l )   # 训练折内估计
                    （该等级训练样本 < 5 例时不建表，回落全局中位数）

预测：  SR̂ = M_l            # 该案件伤残等级 l 在表中
        SR̂ = median(SR_train)  # 等级缺失或不在表中
        SR̂ = 0                 # disability_comp_claim = 0（未主张）
```

分层表输出：`results/stage3/disability_rule_table.csv`（含各等级样本量、SR 中位数、均值、全额支持率，以及跨折估计的均值与标准差）。

## 4. 限制条件

1. **缺少年龄与收入基数**：法定公式需要「人均可支配收入 × 年限 × 系数」，数据集无受害人年龄与年度收入基数，无法直接套用公式，改以伤残等级分层的经验支持率实现。
2. **等级分布极不均衡**：0 级 1722 例、10 级 459 例，而 3 级仅 3 例、4/6 级各 6 例，稀薄等级的分层统计量不稳定（已设最小组样本 5 例并回落全局中位数）。
3. **伤残等级语义为已确认编码**：1 级最重、10 级最轻；若个别文书抽取错误，分层规则会被污染（已有 `disability_abnormal` 标记异常值 25）。
4. **多重伤残**：受害人存在多处伤残时的综合系数无法从单一等级字段还原。
5. **城乡与地区差异**：人均可支配收入的城乡、地区口径差异在本数据集中无法体现。
