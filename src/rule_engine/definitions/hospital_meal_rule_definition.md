# 住院伙食补助费（hospital_meal）规则定义

- 所属分类：**A 类 Rule-based**
- 规则实现：`src/rule_engine/rule_medical.py::HospitalMealRule`（模板 `CapRule`）
- JDI：73.12（排名 2）；有效样本 967；P(SR=1)=0.819，mean_SR=0.930，median_SR=1.000

## 1. 司法依据

- 《民法典》第一千一百七十九条（合理费用列举）。
- 《最高人民法院关于审理人身损害赔偿案件适用法律若干问题的解释》第十条：住院伙食补助费可以参照**当地国家机关一般工作人员的出差伙食补助标准**予以确定。

法律特征：属于**法定标准型**项目，计算方式为「固定日标准 × 实际住院天数」，标准明确、争议空间小，故支持率高度集中于全额支持。

## 2. 输入字段（全部为判前信息）

| 字段 | 说明 |
|---|---|
| `hospital_meal_claim` | 住院伙食补助费请求金额（判前可得） |
| 训练折统计量 `R` | 训练折内 SR=1 样本的 `hospital_meal_claim` 的 90 分位（**仅训练折计算**） |
| 训练折 `median(SR)` | 退化兜底值 |

**禁止使用**：任何 `*_award` 判后字段作为预测输入。

## 3. 计算逻辑

```
R   = quantile( hospital_meal_claim | SR == 1 , q = 0.90 )   # 训练折内估计
SR̂ = min( 1 , R / hospital_meal_claim )                      # claim > 0
SR̂ = 0                                                       # claim = 0（未主张）
```

R 可视为「当地日标准 × 典型住院天数」的经验额度；未超出该额度的请求按标准全额支持，超出部分按额度压缩。

## 4. 限制条件

1. **缺少住院天数**：数据集中无住院天数与日标准字段，无法按法定公式精确计算，只能以训练折经验额度 R 代理。
2. **地区单一**：R 由北京地区样本估计，出差补助标准存在地区差异，外推需重新标定。
3. **陪护人员伙食费**：司法解释中陪护人员伙食费与本人住院伙食补助费口径不同，数据集未区分。
4. **极端小额请求**：极小额请求（如几十元）会被规则判为全额支持，实际可能因计算口径差异略有出入。
