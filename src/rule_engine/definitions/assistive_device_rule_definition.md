# 残疾辅助器具费（assistive_device）规则定义

- 所属分类：**A 类 Rule-based**
- 规则实现：`src/rule_engine/rule_disability.py::AssistiveDeviceRule`（模板 `CapRule`）
- JDI：62.21（排名 6）；有效样本 528；P(SR=1)=0.725，mean_SR=0.866，median_SR=1.000

## 1. 司法依据

- 《民法典》第一千一百七十九条（造成残疾的，赔偿辅助器具费和残疾赔偿金）。
- 《最高人民法院关于审理人身损害赔偿案件适用法律若干问题的解释》第十三条：残疾辅助器具费按照**普通适用器具的合理费用标准**计算；伤情有特殊需要的，可以参照**辅助器具配制机构的意见**确定相应的合理费用标准；更换周期和赔偿期限参照配制机构的意见确定。

法律特征：属于**有标准但需合理性判断**的项目——以「普通适用」为标准上限，超出普通适用档次的豪华型器具费用不予支持，故采用额度锚定规则。

## 2. 输入字段（全部为判前信息）

| 字段 | 说明 |
|---|---|
| `assistive_device_claim` | 残疾辅助器具费请求金额（判前可得） |
| 训练折统计量 `R` | 训练折内 SR=1 样本的 `assistive_device_claim` 的 75 分位（**仅训练折计算**） |
| 训练折 `median(SR)` | 退化兜底值 |

**禁止使用**：任何 `*_award` 判后字段作为预测输入。

## 3. 计算逻辑

```
R   = quantile( assistive_device_claim | SR == 1 , q = 0.75 )   # 训练折内估计
SR̂ = min( 1 , R / assistive_device_claim )                      # claim > 0
SR̂ = 0                                                          # claim = 0（未主张）
```

q 取 0.75（低于医疗费的 0.90）是因为「普通适用」标准的约束强于「凭据据实」，超额部分被削减得更明显。

## 4. 限制条件

1. **缺少器具类型与配制机构意见**：无法区分普通适用型与豪华型，只能用请求金额代理。
2. **更换周期与赔偿期限缺失**：法定要考虑更换周期与赔偿期限，数据集无此字段，规则按单次请求处理。
3. **样本量中等**：528 例有效样本，分位数估计的稳健性弱于 medical（1511 例）。
4. **q 值为方法参数**：0.75 为默认设定，其敏感性应在 Stage 6 消融中检验。
