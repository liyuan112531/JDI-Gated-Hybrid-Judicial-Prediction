# 医疗费（medical）规则定义

- 所属分类：**A 类 Rule-based**
- 规则实现：`src/rule_engine/rule_medical.py::MedicalRule`（模板 `CapRule`）
- JDI：62.59（排名 4）；有效样本 1511；P(SR=1)=0.594，mean_SR=0.900，median_SR=1.000

## 1. 司法依据

- 《民法典》第一千一百七十九条：侵害他人造成人身损害的，应当赔偿医疗费、护理费、交通费、营养费、住院伙食补助费等为治疗和康复支出的合理费用。
- 《最高人民法院关于审理人身损害赔偿案件适用法律若干问题的解释》第六条：医疗费根据医疗机构出具的**医药费、住院费等收款凭证**，结合**病历和诊断证明**等相关证据确定；赔偿义务人对治疗的必要性和合理性有异议的，应当承担相应的举证责任。

法律特征：医疗费属于**凭据据实**计算的项目，法院原则上按有效票据全额支持，仅对缺乏票据、与本次交通事故无关或非必要合理的部分予以削减。

## 2. 输入字段（全部为判前信息）

| 字段 | 说明 |
|---|---|
| `medical_claim` | 医疗费请求金额（判前可得） |
| 训练折统计量 `R` | 训练折内 SR=1 样本的 `medical_claim` 的 90 分位（**仅训练折计算**） |
| 训练折 `median(SR)` | 退化兜底值 |

**禁止使用**：`medical_award`、`award_total`、`support_rate` 等任何判后字段（仅允许在 `fit` 阶段用训练折标签估计统计量，测试阶段不得接触）。

## 3. 计算逻辑

采用**合理额度锚定规则（CapRule）**：

```
R   = quantile( medical_claim | SR == 1 , q = 0.90 )     # 训练折内估计
SR̂ = min( 1 , R / medical_claim )                       # medical_claim > 0
SR̂ = 0                                                  # medical_claim = 0（未主张）
```

- 请求金额未超出「合理额度」R → 全额支持（SR=1）；
- 超出 R → 按 R/claim 线性压缩，体现法院对超额请求的削减；
- 若训练折内全额支持样本不足 5 例，退化为 `R = quantile(claim, 0.90) × median(SR)`。

## 4. 限制条件

1. **缺少结构化医疗证据**：数据集无票据金额、住院天数、自费比例等字段，只能用请求金额作为锚定代理变量。
2. **R 依赖训练折分布**：R 在单一地区（北京）、特定年份样本上估计，外推到其他地区或年份需重新标定。
3. **无法识别个案合理性**：规则无法区分"票据齐全的高额请求"与"虚高的高额请求"，二者在特征上相同。
4. **退化风险**：若某折内全额支持样本过少，规则退化为统计兜底，解释性下降。
5. **上限约束**：预测值强制裁剪到 [0, 1]，与法律规定"判赔不得超过请求"一致。
