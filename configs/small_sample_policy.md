# 小样本项目处理策略（Small-sample Policy）

- 版本：1.0
- 生成阶段：Stage 0 决策修正
- 依据：`results/stage0/item_basic_statistics.csv`
- 生效范围：Stage 1 – Stage 7

---

## 1. 背景

Stage 0 审计给出 16 个赔偿分项的有效样本量（`claim_i > 0`）：

| 分项 | claim>0 | 分项 | claim>0 |
|---|---:|---|---:|
| transport | 1598 | assistive_device | 528 |
| medical | 1511 | other | 368 |
| property_loss | 1500 | **future_medical** | **172** |
| lost_income | 1411 | **accommodation** | **104** |
| nutrition | 1281 | **death_comp** | **78** |
| nursing | 1245 | **funeral** | **78** |
| mental_solatium | 1079 | | |
| hospital_meal | 967 | | |
| appraisal | 843 | | |
| disability_comp | 614 | | |

样本量跨度达 20 倍（78 → 1598），直接使用统一阈值切分会同时造成两类错误：把大样本的规则性项目误送入模型，以及把小样本的裁量性项目强行判为规则项目。

## 2. 处理原则（已确认）

1. **不删除任何项目**——16 个分项全部保留在数据集中。
2. **保留全部项目统计**——每个分项的支持率分布、样本量、异常统计均完整输出，不受样本量影响。
3. **禁止因样本量不足直接判定为规则项目**——样本量与"司法确定性"是两个不同维度：样本少不等于规则明确（如死亡赔偿金有法定计算标准但案件少；精神损害抚慰金样本多但裁量空间大）。
4. **标记而非丢弃**——小样本项目标记 `small_sample = true`，只做探索性分析，不参与主要模型排名。

## 3. 统计理由

- 在 5 折 × 3 次重复的交叉验证下，`n = 78` 的每折训练样本约 62 例，模型性能估计的标准误会显著大于候选模型之间的真实性能差异，排名结果不可靠（排名噪声 > 组间差异）。
- 小样本分项的 CV 误差置信区间与主流分项严重重叠，将其纳入"最佳模型"排名会污染结论。
- 极端小样本（78 例）下，超参数搜索极易过拟合验证折，产生虚假的性能提升。

## 4. 小样本项目清单与标记

| 分项 | claim>0 | `small_sample` | 说明 |
|---|---:|---|---|
| `death_comp` | 78 | `true` | 死亡赔偿金，仅死亡案件主张 |
| `funeral` | 78 | `true` | 丧葬费，仅死亡案件主张 |
| `accommodation` | 104 | `true` | 住宿费，主张率低 |
| `future_medical` | 172 | `true` | 后续医疗费，主张率低 |

> 说明：上述清单为**样本量维度**的标记，与 Stage 2 的 A（规则）/ B（机器学习）归属**正交**。一个项目可以同时属于 A 类或 B 类并被标记 `small_sample = true`。

## 5. 小样本项目的处理方式

### 5.1 探索性分析（允许）

- 支持率分布描述（均值、中位数、标准差、零支持率占比、全额支持占比）
- 与伤残等级、责任比例、请求金额量级的交叉分析
- 单变量可解释性检查（请求金额对支持率的解释力）
- 法律规则对照（该分项是否存在明确的法定计算标准）

### 5.2 不参与的内容（禁止）

- 不参与**主要模型排名**（Stage 4 的模型横评主表不含 C 类项目）
- 不参与**最优模型选型**的结论外推
- 不进行超参数搜索（避免验证折过拟合）
- 结果单独成表并标注 `exploratory`，论文中置于附录或单独小节

### 5.3 在系统集成中的回退规则

最终案件级系统需要每个分项的预测支持率，因此 C 类项目仍需给出预测值：

- 默认回退：使用**规则基线或分项支持率中位数**（由 Stage 2 的 A/B 归属决定：属 A 类用规则公式，属 B 类用分项中位数）
- 该回退策略在 Stage 6 消融实验中作为独立变量检验：比较"C 类回退"与"C 类强制建模"对案件级 `SR_total` 指标的影响
- 若回退与强制建模的最终系统指标差异不显著，则在论文中说明小样本项目对系统级结论影响有限

## 6. 与旧策略的差异

| 维度 | 旧策略（已取消） | 现行策略 |
|---|---|---|
| 划分依据 | `n >= 100 → ML`，`n < 100 → Rule` | JDI 指数 + 法律规则先验（Stage 2） |
| 样本量作用 | 直接决定建模与否 | 仅标记 C 类、标注证据强度 |
| 小样本处理 | 强制转为规则项目 | 保留原归属，标记并做探索性分析 |
| 项目数量 | 可能被剔除 | 16 项全部保留 |

## 7. 禁止事项

- 禁止删除小样本项目或其样本
- 禁止把小样本作为"该项目司法确定性高"的证据
- 禁止让小样本项目参与主要模型排名或最优模型结论
- 禁止在小样本项目上做超参数搜索

## 8. C 类定义调整（Stage 2 决策冻结）

**不再采用 `n < 100` 唯一标准。** C 类正式定义为：

> **C 类 = Small-sample / Low-support-risk category**
> （小样本 / 低支持风险类别）

判定依据（三条，综合判定）：

1. **样本规模**：有效样本（`claim > 0`）显著少于主流项目；
2. **SR 分布特殊性**：支持率高度集中于 0 或 1 等极端值，或分布形态不稳定；
3. **预测稳定性不足**：交叉验证下性能估计方差过大，模型排名不可靠。

C 类成员与证据：

| 项目 | 样本量 | 分布证据 |
|---|---:|---|
| `death_comp` | 78 | P(SR=1)=0.577，集中于全额支持 |
| `funeral` | 78 | SR 中位数 0.970，集中于高值 |
| `accommodation` | 104 | P(SR=0)=0.663，极端驳回集中 |
| `future_medical` | 172 | P(SR=0)=0.826，极端驳回集中且依赖鉴定结论 |

**C 类与 A/B 归属正交**：四项 C 类项目的 A/B 建议均为 Rule-based，但仅作标记，
不因样本量自动判为规则项目，也不进入主要模型排名。

### 8.1 C 类处理方案：Rule-informed fallback

最终案件级预测按法律规则可用性分三级回退，回退统计量**仅在训练折内计算**：

| 优先级 | 条件 | 处理方式 | 适用项目 |
|---|---|---|---|
| 优先级 1 | 存在明确法律计算公式 | 规则计算 | `death_comp`、`funeral` |
| 优先级 2 | 存在规则约束但无完整公式 | 规则约束 + 训练集 SR 统计先验 | `accommodation`、`future_medical` |
| 优先级 3 | 无规则可依 | 训练集 SR 中位数 | （当前无项目落入） |

- 具体公式在 Stage 3 定义并落地；
- 回退策略作为独立消融变量在 Stage 6 检验（C 类回退 vs C 类强制建模）；
- 禁止在训练/测试划分前使用全量统计先验；
- 禁止删除 C 类项目或其样本；
- 禁止 C 类项目直接进入主要模型排名。
