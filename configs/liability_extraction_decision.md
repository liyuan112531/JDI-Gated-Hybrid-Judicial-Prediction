# 责任比例重新抽取决策（Re-extraction Decision）

- 版本：1.0
- 生成阶段：Stage 0 决策修正
- 结论：**不重新回溯 docx 抽取责任比例（NOT_REEXTRACT）**

---

## 1. 决策

不对 2380 篇原始裁判文书重新执行责任比例字段抽取。

## 2. 决策理由

1. **成本过高**：2380 篇文书的重新解析、抽取、人工核验链路成本高，且需要重建抽取规则与质量控制流程，投入产出比不合理。
2. **研究重心不符**：本研究的核心科学问题是"规则计算 + 数据驱动的支持率预测框架"以及"分项司法确定性的分层"，责任比例字段的抽取质量属于数据工程子问题，不是本研究的贡献点。
3. **缺失机制本身具有研究价值**：责任比例在 81.3% 的记录中未被抽取到（编码为 0），这是一个真实存在的司法数据质量问题。将其作为数据质量讨论的一部分，反而能提升论文对真实司法数据可用性的讨论深度——即回答"**在判前信息不完整（且缺失机制未知）的条件下，司法支持率预测的上限在哪里**"。

## 3. 采用的处理方案

按 `configs/liability_strategy.json` 执行三字段方案：

| 字段 | 规则 | 用途 |
|---|---|---|
| `liability_ratio_raw` | 原样保留（含 0 与 NaN） | 审计追溯、敏感性分析基线 |
| `liability_ratio_clean` | `raw == 0 → NaN`；`raw > 0` 保留 | 主策略建模字段 |
| `liability_missing` | `clean` 缺失 → 1，否则 → 0 | 缺失指示变量，保留缺失机制信息 |

- 主策略（`missing_as_zero_code`）：0 视为缺失编码，采用缺失指示变量 + 填补，填补统计量**仅在训练折内拟合**。
- 敏感性策略（`keep_zero`）：保留 0 作为真实责任比例，用于检验主策略结论的稳健性。
- 禁止删除样本，禁止用判后字段推断责任比例。

## 4. 论文中的报告要求

必须在论文中明确报告以下内容：

1. 责任比例字段存在**编码缺失问题**：2380 条记录中 1935 条（81.3%）取值为 0，434 条（18.2%）为有效正值，11 条（0.5%）为空。
2. 该 0 值经统计检验判定为"未抽取"而非"被告无责"，证据是零值组的案件实际支持率均值 0.669、中位数 0.732，98.0% 的案件存在判赔——与"被告无责"的法律后果矛盾。
3. 本研究采用**缺失指示变量 + 填补**策略，并报告"按真实 0 处理"的敏感性分析结果。
4. 在局限性章节说明：责任比例信息的大面积缺失限制了模型的判前信息完备性，是本研究性能上限的重要约束条件之一；未来工作可结合文书正文结构化抽取提升该字段的覆盖率。

## 5. 风险与缓解

| 风险 | 缓解措施 |
|---|---|
| 缺失机制非随机（MNAR），填补引入偏差 | 保留 `liability_missing` 指示变量，让模型显式学习缺失模式；报告缺失组与非缺失组的分组性能 |
| 责任比例是关键判前特征，缺失削弱预测力 | 以基线对比量化该损失：报告"含责任比例"与"不含责任比例"两组特征集的指标差异 |
| 读者质疑 0 值判定 | 给出零值组的支持率分布证据（Section 8.1 表），并提供敏感性策略对照 |

## 6. 未来工作（不在本研究范围内）

- 基于文书正文的责任比例结构化抽取（正则 + 语义角色标注 + 大模型抽取）
- 抽取结果的人工抽样核验与置信度标注
- 多来源交叉验证（如交警责任认定书字段）

## 7. 判前时点界定与程序法理说明（Pre-adjudication Timing Justification）

> 本节回应审稿中对 `liability_ratio` 与 `disability_level` 两个特征
> "是否属于判前可得信息"的疑问，与 `data/DATA_DICTIONARY.md` 同步维护。

### 7.1 预测时点定义

本研究的预测时点为**判决作出前（Pre-judgment / Pre-adjudication decision
support）**的司法辅助场景：即庭审举证、质证与辩论程序完毕、法官对 16 项法定
赔偿分项逐一确定判赔金额**之前**。它**不是**"原告起诉立案时点（Filing
time）"——因此答辩期内由被告提交、庭审质证环节由双方呈现的证据所支撑的
司法认定（如伤残等级鉴定意见），在本时点定义下属于合法的判前输入。

### 7.2 程序法依据

1. **交通事故责任比例**：由公安机关交通管理部门在诉前作出的《道路交通事故
   认定书》载明（《中华人民共和国道路交通安全法》第七十三条）。该认定书在
   起诉前即已生成并随诉讼材料进入法院，法院实体判决时点必然晚于其作出时点，
   故属客观已生成的判前信息。
2. **伤残等级**：由具备资质的司法鉴定机构出具《司法鉴定意见书》确定，通常
   在诉前委托鉴定或庭审质证环节出示（《民事诉讼法》第六十六条证据种类之
   "鉴定意见"）。在本研究定义的"判决作出前"时点，鉴定意见已经或正在质证，
   属于法官落槌前可得的客观输入。

### 7.3 抽取缺失治理（Substantive Missingness）

`dataset_anonymized.csv` 中仅 **18.24%（434/2,380）** 的案件具有大于 0 的
责任比例数值，其余 **81.76%** 编码为 0。统计检验证实该 0 值属于文书非结构化
叙述导致的**信息抽取缺失**而非被告无责：零值子群的真实案件级支持率均值高达
**0.6689**（若真为被告无责，支持率应趋近于 0；见上表第 4 节第 2 条证据链）。

处理方案：特征工程将 `liability_ratio` 拆解为
**清洗后责任比例（`liability_ratio_clean`）+ 缺失标记（`liability_missing`）**，
填补统计量仅在训练折内拟合；并在论文第 3.2 节与第 5.5 节如实报告这一数据
局限——两种编码策略（主策略 `missing_as_zero_code` vs 敏感性策略
`keep_zero`）的案件级 MAE 差异仅 **0.0001**，结论对编码选择稳健。

### 7.4 与防泄漏体系的关系

无论 `liability_ratio` / `disability_level` 的取值如何，任何
`*_award`、`award_total`、`support_rate` 等判后字段均被
`configs/feature_blacklist.json` 硬性拦截（Stage 1 起自动校验，
`results/stage1/stage1_leakage_check.json` 4/4 PASS）；本节所论证的仅是
上述两个司法认定字段的**时点合法性**，不改变黑名单的任何边界。
